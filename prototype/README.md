# Goreun

홈 · 고른 · 설정으로 이어지는 화이트/블랙 모바일 사진 정리 체험입니다. 기존 통합판과 같은 Site ID와 비공개 범위를 유지합니다.

## 구조와 실행
- web/: 브라우저 원본. 로컬 Pretendard 폰트, 기기 사진 준비, 비교, 갤러리 용량 집계
- worker/index.mjs: 서버 Gemini API, 입력과 응답 검증, 정적 파일 응답
- scripts/build.mjs: web의 필요한 파일을 Worker에 포함해 dist/server/index.js 생성. API 키는 빌드에 포함하지 않음
- npm run build / npm test
- 로컬 실제 API 테스트: stty -echo 후 node scripts/preview.mjs 실행, 비밀 환경 설정 JSON을 stdin으로 전달. 키를 파일에 저장하지 않음

## Gemini 연결
Sites 런타임 GEMINI_API_KEY(비밀)와 GEMINI_MODEL을 사용합니다. 현재 모델은 gemini-3.5-flash-lite입니다.
분석 버튼 → 전송 동의 → 압축 JPEG와 입력 기준·취향 참고 사진을 서버에서 Google Gemini로 전송 → 사진별 근거와 포인트·후보 분류 → 사용자가 최종 선택.
취향 참고 최대 10장, 분류 대상 2~30장, 후보 2~4장. 원본 사진과 파일명, SNS 계정명은 전송하지 않습니다. 미리보기는 최대 640px, JPEG base64 105,000자 이내입니다. 서버 요청 크기·id·형식·전체 사진 응답을 검사합니다.
동의 없이 API로 사진을 보내지 않습니다. 기기에서만 정리 옵션도 유지합니다. Gemini 실패 시 실패 사실을 알리고 사용자 선택으로 기본 정리를 진행합니다. 요금과 한도는 해당 Gemini 프로젝트의 설정에 따릅니다.
서버는 사진/기준을 DB나 로그에 저장하지 않습니다. Google의 전송 데이터 처리는 Gemini API 정책에 따릅니다. 모델이 반환한 판단은 사용자가 확인합니다.

## 기기 안의 기본 정리
밝기·윤곽·유사도와 MediaPipe 얼굴 표정·눈 감음·얼굴 축 분석을 사용합니다. 모델 파일은 공식 배포 경로에서 다운로드하고, 기본 정리 사진은 외부 분석 서버로 보내지 않습니다. 자유 문장 전체 이해는 Gemini 모드에서 제공합니다.

## 갤러리와 설정
최초 갤러리 팝업은 웹 앱의 안내이며 OS의 전체 갤러리 권한이 아닙니다. 실제 선택한 사진·영상의 개수/용량만 홈에서 마지막 연결 기준으로 표시합니다. 휴대폰 전체 잔여 공간은 조회하지 않습니다. 원본 사진은 자동으로 이동/삭제하지 않고 정리 결과를 폴더별 ZIP으로 내보낼 수 있습니다.
타겟·정리 대상·취향·공통 기준을 변경할 수 있습니다. 인플루언서는 SNS별 취향과 게시 초안/공유를 사용합니다. SNS 계정 인증·자동 게시 및 포토북은 미연결입니다.

## 검증
입력·전송 동의·압축 payload·Gemini 응답 전체 ID·개수 검증·키 노출 방지·기본 분류·ZIP·갤러리 집계 테스트를 실행합니다.
가상 가족 예시 3장으로 실제 Gemini API와 모바일 전체 흐름에서 눈 뜬 컷/풍경 컷 선택, 눈 감은 컷 제외, 사진별 근거 및 확대 포인트를 확인했습니다.

## 갤러리 허용 단계 간소화
첫 진입의 허용은 앱 내 이용 동의만 저장하고 팝업을 닫습니다. 사진 선택창은 열지 않습니다. OS 권한을 실제로 획득했다고 표시하지 않으며, 실제 사진은 고른에서만 선택합니다. 아직 선택한 사진이 없으면 홈에 용량을 지어내지 않고 사진 선택 후 확인할 수 있다고 표시합니다.

## 개인 인스타그램 사진 선정 흐름 (2026-11-11)
- 홈 → 이번 게시물 사진 선택 → 원하는 느낌 선택·입력 → 후보 1~4장 비교 → 직접 선택 → 선택 사진 ZIP 저장.
- 설정은 좋아하는 사진 최대 10장과 공통 기준 두 항목입니다. 사용자 유형·사진 대상 설문은 화면에서 제거했습니다. 기존 취향 사진 저장 프로필은 유지합니다.
- 인스타그램 계정 연동은 준비 중입니다. 실제 계정 인증·게시물 가져오기는 미구현이며, 참고 게시물 사진을 직접 추가하는 방식으로 체험합니다. 계정명만으로 학습하지 않습니다.
- 인스타그램 열기는 웹사이트를 여는 동작으로, 자동 업로드는 아닙니다. 좋아요 수나 인기도를 예측하지 않습니다.
- Gemini에는 항상 Instagram 용도를 전달하고, 원하는 분위기와 실제 보이는 차이를 연결해 설명하도록 요청합니다. 로컬 기본 정리의 문장 이해에는 한계가 있습니다.
