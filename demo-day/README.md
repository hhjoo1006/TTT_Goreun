# Goreun 데모데이 발표 자료

공개 발표: https://goreun-demoday.growthcamp-6278.chatgpt.site/

## 구성
- 표지와 서비스 한 줄 소개를 포함한 7장 HTML 발표 자료
- 평면으로 펼친 사진 후보 6장
- 원본 애니메이션 GIF 3개
- 폰트와 이미지를 포함한 로컬 실행용 파일

## 실행
이 폴더 전체를 내려받아 `index.html`을 브라우저로 여세요. `assets` 폴더를 함께 유지해야 합니다.

- 방향키 또는 하단 버튼: 장표 이동
- F: 전체 화면
- G: 전체 목차
- H: 도구 숨기기
- 데모 장표의 GIF 다시 보기: 애니메이션 재시작

## 자료 주의사항
- 12.45분은 제공 자료의 수치이며 조사 원문·연도·문항은 확인이 필요합니다.
- 시장 규모 확인 장은 원본과 같이 제목만 유지했습니다.
- 시연 GIF는 예시입니다. 실제 고객 성과를 뜻하지 않습니다.
